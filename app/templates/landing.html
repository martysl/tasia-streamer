Built for actual DJ use

Everything visible. Everything reachable.

No tab maze. No tiny mystery controls. Tasia Streamer keeps the important parts of a live set on one screen.

🎛️

SAM-style workstation layout

Library on the left, live deck and queue in the middle, set tools and sources on the right.

↕️

Drag & drop queue

Reorder songs naturally. Prefetched tracks stay visibly locked so the UI never lies about what plays next.

📁

Folders that behave like folders

Browse subfolders, search globally, save favourites from Suno/online/remote sources, or queue an entire folder tree in one click for party mode.

⏱️

Set timing & ETA

See total queue time, playlist length, predicted play time for every track and when your set ends.

👥

Real multi-user separation

Each account gets its own music root, queue, playlist, stream profile, remote sources and settings.

🌐

Bring your own library

Local folders, Universal Search, Suno, WebDAV, FTP/FTPS, Jellyfin, Audius, Jamendo and direct-stream Stremio addons all feed into the same stable queue.

Pimp-my-DJ, basically

Sources and tools as addons.

The playout core stays boring and reliable. Extra music sources, browsers, generators and DJ helpers can plug into the workstation without rewriting the radio engine every time.

Optional, not bossy

Ask your own AI for DJ advice.

Point Tasia Streamer at an OpenAI-compatible Base URL, choose your model, and keep the API key server-side. Ask what to play next, how to balance the set or how to rescue a party that suddenly went weird.

Advice-only by default. The AI does not secretly reorder or start your queue.
